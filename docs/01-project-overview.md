# Project Overview

## Project Name

Evolve Inventory Management

## Purpose

Evolve Inventory Management is designed to help an organization track and manage company assets and devices throughout their lifecycle. The system will provide accurate asset visibility by combining asset registration, RFID tagging, handheld scanning, movement tracking, audit verification, and reporting.

## Project Scope

The system will cover the following areas:

- Track company assets and devices.
- Assign RFID tags to assets.
- Monitor asset location, status, and movement.
- Support handheld scanning using RFID-enabled devices.
- Provide a web dashboard for management, reporting, searching, and administration.

## Business Objectives

The main objectives of the system are:

- Improve accuracy of asset records.
- Reduce manual asset tracking work.
- Provide clear asset ownership, location, and status information.
- Support audit and stock take activities.
- Maintain full movement history for each asset.
- Improve accountability for assets assigned to staff, departments, or locations.
- Provide centralized reporting for management and operational teams.

## Users

The system will support the following user groups:

- Admin
- Store or inventory staff
- IT staff
- Auditor
- Department user

## High-Level Capabilities

The system will allow users to:

- Register new assets.
- Update asset information.
- Link RFID tags to assets.
- Search assets using asset code, RFID EPC, serial number, barcode, or QR code.
- Check assets in and out.
- Transfer assets between locations.
- Assign assets to staff, custodians, or departments.
- Return assets.
- Perform audit or stock take.
- Record repair and disposal status.
- Generate reports.

## Platforms

The system will have two main user interfaces:

- Web application for dashboard, asset management, reports, and user administration.
- Handheld mobile application for RFID scanning, asset verification, transfer, and audit operations.

## Expected Outcome

At the end of development, the organization should have a centralized inventory management platform that can track each asset from receiving until disposal. Each asset should have a clear record of identity, RFID tag, assigned user or department, current location, condition, status, and historical movements.

## Assumptions

- Each physical asset will have a unique asset code.
- Each RFID tag will have a unique RFID EPC.
- An RFID tag can only be linked to one active asset at a time.
- Handheld devices will connect to the backend API through a network connection.
- User permissions will be controlled by role-based access control.
- Reports may be exported for management, audit, and operational needs.
